# csvfill

The program should work like this:

```sh
csvfill my_df.csv < new_data.csv
```

Similar to patch.

Options:

  -d  delimiter. Comma by default.
  -1  FIELD to use as id in file 1.
  -2  FIELD to use as id in file 2.

---


## Bugs

- The program can't handle embedded new lines in fields.
